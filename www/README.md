# LDkit website

Source of [ldkit.io](https://ldkit.io): a static site built with
[Vite+](https://viteplus.dev). The landing page, documentation and ontology
pages are Preact components rendered to HTML, with no client-side JavaScript.
The API reference is generated by TypeDoc, whose pages use JavaScript for
navigation and search.

- `routes.tsx` lists the pages in `pages/`. `site-plugin.ts` is a Vite plugin
  that renders them to HTML files during `vp build`.
- Documentation content comes from [`../docs`](../docs). Pages and sidebar
  follow `../docs/table-of-contents.json`. Markdown is rendered by
  `lib/markdown.ts`, a port of the `deno.land/x/gfm` renderer, and styled by
  `styles/gfm.css` plus Tailwind CSS (`styles/site.css`).
- The API reference at `/api/` is generated by TypeDoc (`typedoc.json`) from
  the library sources in `..`; `tsconfig.typedoc.json` maps Deno `npm:` imports
  to packages installed here. The site header and footer are added to every TypeDoc
  page inside shadow roots (`renderApiChrome` in `routes.tsx`, styled by
  `styles/api.css`).

```sh
npm install
vp build     # production build into dist/
vp check     # format, lint and type-check (Oxfmt, Oxlint, tsrs)
vp test      # Vitest
```

To preview the site locally, run `netlify serve` in the repo root: it runs the
build and serves `dist/` like Netlify does. It doesn't watch for changes, so
restart it after editing.

Without a global `vp`, use `npx vp …` or the matching `npm run` scripts.
Deployed by Netlify using [`../netlify.toml`](../netlify.toml).
